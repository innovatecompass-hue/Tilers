# Client Launch Tasks — Precision Tile Co.

## Off-Site SEO (Manual — Client Actions)

- [ ] Claim and fully complete **Google Business Profile** (photos, hours, services, website URL)
- [ ] Create free listing on **Houzz** — houzz.com/pro
- [ ] Create free listing on **Angi** — angi.com
- [ ] Create free listing on **Thumbtack** — thumbtack.com
- [ ] Create free listing on **Yelp** — biz.yelp.com
- [ ] Create free listing on **Yellow Pages** — yellowpages.com
- [ ] Create free listing on **HomeAdvisor** — homeadvisor.com
- [ ] Verify NAP (Name, Address, Phone) is identical across all listings and the website
- [ ] Ask 5–10 past customers for a Google review (send direct review link)
- [ ] Submit sitemap to **Google Search Console** — search.google.com/search-console

## Additional SEO / GEO (Website Builder Actions)

- [ ] Create city × service landing pages (e.g. `/shreveport-bathroom-tile`, `/bossier-city-kitchen-backsplash`)
- [ ] Add real project photos with SEO filenames and alt text (e.g. `shower-tile-installation-shreveport-la.jpg`)
- [ ] Set up Google Analytics 4 — add GA4 tag to `<head>`
- [ ] Audit Core Web Vitals in Google Search Console and fix any issues
- [ ] Add internal links between service sections using keyword-rich anchor text

## Domain (Optional but Recommended)

- [ ] Purchase a custom domain (e.g. precisiontileco.com)
- [ ] Add domain in Vercel dashboard → Settings → Domains

## Ongoing (Monthly)

- [ ] Post a photo to Google Business Profile
- [ ] Ask every new happy customer for a Google review
- [ ] Respond to all new reviews within 48 hours
